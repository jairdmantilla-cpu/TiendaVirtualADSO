# TiendaVirtualADSO
**Objetivo:** Desarrollar una plataforma web moderna y segura para la venta de productos en línea, optimizando la experiencia de usuario y la gestión de inventario.

**Funciones principales:**
1. Catálogo de productos interactivo con filtros de búsqueda.
2. Carrito de compras con pasarela de pagos integrada.
